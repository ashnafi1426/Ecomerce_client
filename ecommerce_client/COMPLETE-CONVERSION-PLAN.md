## 🎨 CONVERSION METHODOLOGY

For each page:
1. **Read HTML** from `website/` folder
2. **Extract Design**: Structure, layout, CSS styles
3. **Convert to React**:
   - HTML → JSX
   - CSS classes → inline style objects
   - Static content → useState with mock data
   - Forms → controlled components
   - Links → React Router Links
4. **Add React Features**:
   - useState, useEffect hooks
   - API integration placeholders
   - Toast notifications
   - Loading states
   - Error handling
5. **Maintain Design**: Keep exact visual appearance from HTML
